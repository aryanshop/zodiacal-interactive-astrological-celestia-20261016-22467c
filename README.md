# Zodiacal: Interactive Astrological & Celestial Chart Builder

## Purpose
Zodiacal is an interactive celestial mechanics and ephemeris visualization tool built with vanilla HTML5, CSS3, and JavaScript. It computes planetary positions, zodiacal divisions, astrological houses, and geometric aspects entirely client-side without external servers, APIs, or data collection.

## Features
- **Temporal Control & Time Scrubber:** Pick any date and time or use the real-time simulation speed warp to watch orbital motion.
- **Geographic Observer Coordinates:** Adjust latitude, longitude, or pick global city presets to calculate local horizon points.
- **Dual Visualization Modes:** Toggle instantly between a traditional 360-degree Astrological Natal Chart Wheel and an astronomical Celestial Sphere projection.
- **Aspect Geometry Detection:** Automatically calculates conjunctions, oppositions, trines, squares, and sextiles with exact orb tolerances.
- **Celestial Almanac:** Displays Julian Date, Local Sidereal Time, Season, and real-time moon phase calculations.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.
3. Enjoy exploring celestial mechanics locally and securely!

## Static Project Disclaimer
This is a 100% static client-side project with zero tracking, cookies, external fonts, or network requests.
